## 2. 回合与阶段

0 基回合 `turn ∈ [0,77]`（共 78 回合），阶段机为剧本私有枚举，对外投影 `StageId`。

| 中文 | 日文 / 代码 | 决策点 | 主体行为 |
|---|---|---|---|
| 回合开始 | `Begin`（StageId 0） | ✗ | 结算上回合遗留的源泉选择；解锁/再选择回合补触发；生成事件；发温泉券（2/36/60）；执行事件链 |
| 人头分配 | `Distribute`（1） | ✗ | 刷新剧本面板（锁面板）；比赛回合清空分布，否则分配人头 + 红点 + 分身 |
| 入浴 | `Bathing`（2） | **✓** | 有券且温泉效果未生效时，选择「用券 / 不用券」 |
| 训练 | `Train`（3） | **✓** | 选择训练 / 比赛 / 休息 / 出行 / 治病 / PR |
| 回合后 | `AfterTrain`（4） | ✗ | 结算待处理事件（加练、红点、友人点击、比赛、挖掘奖励）；温泉效果回合数 −1 |

- **源泉选择 / 装备升级不是回合阶段**（`code`：寄生于 `Begin` 的 `pending_selection` 流程）；新仓是否升格为独立阶段，实现时按阶段号稳定性决定。
- 合宿：`turn ∈ [36,40) ∪ [60,64)`，不挖掘、不出门、不 PR、不治病，训练等级固定 5。
- 决赛期（ファイナルズ）：`turn ≥ 72`，73/75/77 为强制比赛回合。

| 挖掘力 | 掘削力 | `dig_power[3]` | 蓝因子档 + 属性档位 + 装备等级三部分加算，见下 |
| 挖掘量 | 掘削量 | `dig_value` | `floor(基础值 × (100+挖掘力)/100)`；跨地层公式不对称 ⚠️ |
| 挖掘进度 | — | `dig_progress[3]` | **只增不减**，挖完不清零；每满 30 触发一次奖励 |
| 剩余挖掘量 | — | `dig_remain[3]` | 初始化自 `dig_volume`，挖完归零 |
| 挖掘奖励 | — | `dig_bonus[3][6]` | 砂 [2,1,0,0,2]−3 / 土 [2,0,1,2,0]−3 / 岩 [0,1,2,0,2]−3（速耐力根智、体力） |
| 挖掘完成 | 掘削完了 | `onsen_state[i] = true` | 发放温泉券并触发源泉选择 + 装备升级 |
| 挖掘装备 | 掘削装備 | `dig_level[3]`、`dig_tool_level` | 等级 1–6，加成 0/30/50/70/100/130；`dig_tool_name` = 砂 / 土 / 岩 |
| 蓝因子档 | 青因子 | `dig_blue_count` | `ceil(blue_count/3)`，与星数无关 |
| 属性档位 | — | `dig_stat_ranks` = [0,100,200,300,400,600,1000,1200] | 五维落在哪一档决定加成 |
| 属性档位加成 | — | `dig_stat_bonus[3][8]` + `dig_stat_bonus_types[3][3]` | 表行由 `types` 指定；旧代码注释写反过，**以数据为准** |
| 剧本链接 | シナリオリンク効果 | `link_effect` | 命中对应马娘 / 支援卡时该地层挖掘力 +10%（可叠加） |
| 地形资料 | — | `onsen_info[].dig_volume` | 每层需求量，见 §3 |

- 挖掘力三部分：①蓝因子 `dig_blue_bonus`；②属性档位 `dig_stat_bonus`（按 `types` 映射）；③装备 `dig_tool_level[dig_level]`。
- 跨地层：当前层挖掘力**含**链接加成、下一层**不含**，且当前层取剩余量整数不取 `floor`——按旧实现口径，移植时勿「顺手对称化」。
- 属性档位映射（以 `data` 为准）：砂层 ← 速/智/耐，土层 ← 根/速/力，岩层 ← 力/智/耐。
- PR 的挖掘基础值按 1 个客人计（NPC 不参与模拟，见 §7.1）。

## 11. 术语表使用约定

1. **一物一词**：同一字段在文档、代码注释、前端文案中只用一个中文词；日文原词只作对照列。
2. **数据名优先**：日本原名与数据中文名冲突时，以 `scenario_onsen.json` 现名为准（本表 §3）。
3. **索引与 id 分开写**：配置与代码用「索引」（0 基），数据与协议用「id」（1 基），文档必须写明是哪一种。
4. 新词先进本表、再进代码；实现期若发现新术语，就地补表。

## 12. 与旧词汇表的差异（迁移提示）

- 旧 `umaai_next/docs/game/game_glossary.md` §温泉杯（14 条）为归档条目，本表取代其作为温泉术语事实源；
